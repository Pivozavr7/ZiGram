# ZiGram: план v3

Заменяет v2. Что изменилось:

- Статус синхронизирован с реальным кодом (в v2 и README он отставал: логин в GUI уже работает).
- Добавлен **этап R: разрезать монолиты**. Он идёт раньше любых новых фич в GUI.
- Структура модулей и лимиты размера теперь заданы в `AGENTS.md` (раздел «Rule zero»). План ссылается на них, а не дублирует.
- GUI-роадмап разбит на маленькие шаги по слоям `app/` → `ui/`.
- Добавлен **логотип в SVG** (раздел 5) и обязательный процесс: на каждое рабочее состояние коммит и push, на каждый этап обновление README (правила в `AGENTS.md`, раздел «Git and README discipline»).

Остаётся без изменений: Zig 0.17.1, Dear ImGui + SDL3 GPU, TDLib 1.8.70 через `libtdjson.so`, Linux, Apache-2.0.

## 2. Этап R: разрезать монолиты (до любых новых фич)

Правила: каждый шаг это чистый перенос кода (без изменения поведения), один шаг = одна задача, до и после `zig build test` с теми же тестами, после шага `wc -l` по затронутым файлам. Детали в `AGENTS.md`.

**R1. `td.zig` → `core/td/`** (897 строк → файлы по 100-200)
Порядок «от листьев к корню», чтобы каждый шаг собирался:
- [ ] `search.zig` (кандидаты путей к библиотеке)
- [ ] `options.zig` (разбор option-ответов)
- [ ] `queue.zig` (`EventQueue`)
- [ ] `library.zig` (DynLib, таблица символов, версия, уровень логов)
- [ ] `receiver.zig` (цикл потока-приёмника)
- [ ] `client.zig` (`Client`: send, poll, сопоставление по `@extra`)
- [ ] `root.zig` (реэкспорт; `zigram.td.*` продолжает работать)

**R2. `store.zig` → `core/store/`**
- [ ] `user.zig`, `chat.zig`, `message.zig`, `file.zig`, `root.zig`; разбор payload лежит рядом со своей сущностью

**R3. `gui/main.zig` → слои `app/` и `ui/`** (648 строк, `main` на ~210 → `main` до 40)
- [ ] `app/config.zig` (загрузка `config.zon`, ошибки старта, путь к exe)
- [ ] `app/log.zig` (debug-лог, маскировка `api_hash`)
- [ ] `app/session.zig` (старт ядра, владение клиентом, слив событий за кадр, pending-запросы)
- [ ] `app/login.zig` или `state.zig` (чистая функция «состояние авторизации → какой экран», с тестами)
- [ ] `ui/gfx.zig` (extern-объявления шима, enum событий)
- [ ] `ui/widgets.zig` (текст, подсказка, ошибка, поле пароля)
- [ ] `ui/screens/login.zig` (экраны: телефон, код, пароль, QR)
- [ ] `gui/main.zig` остаётся только окном и циклом кадра

**R4. По желанию, когда дойдём:** `core/auth.zig` (371) → `auth/` (состояния, запросы, разбор). Лимит 500 не нарушен, но 300 уже превышен.

**R5. Долги, которые заодно закрыть отдельными маленькими задачами**
- [ ] Поле 2FA-пароля: буфер сейчас 64 байта (максимум 63 символа). Сделать не меньше 256 и обнулять буферы пароля и кода после отправки
- [ ] CI: job `build` гоняет ещё и `zig build test`
- [ ] README: отметить реально сделанное (логин, QR), синхронизировать роадмап
- [ ] `.gitignore` исключает `AGENTS.md` и `ZiGram-plan.md`, а README на `AGENTS.md` ссылается: либо убрать файлы из игнора, либо убрать ссылку из README

**Критерий готовности этапа R:** нет файла больше 500 строк (цель: больше 300 нет), нет функции больше 70 строк, `main` в обоих исполняемых до 40 строк, тесты те же и зелёные, `core/` и `app/` не импортируют ничего из GUI.

## 5. Логотип и процесс

**Процесс на каждом шаге** (обязательно, детали в `AGENTS.md`):
- рабочее состояние (`zig build` и `zig build test` зелёные) = отдельный коммит + сразу `git push`
- закрыли пункт плана или этап = в том же коммите отмечены чекбоксы в `README.md` и `ZiGram-plan.md`; этап не считается законченным, пока README не обновлён
- в README не пишем того, чего ещё нет

## 6. Риски

- **Монолиты возвращаются.** Главный риск проекта. Защита: лимиты в `AGENTS.md`, проверка `wc -l` до и после, отдельный шаг на каждый разрез. Если агент снова тянет код в большой файл, это повод остановиться и вынести его
- **Текст в ImGui.** IME, цветной эмодзи, переменная высота пузырей; RTL не поддерживается совсем. Проверять рано (G1)
- **Кадр не должен блокироваться.** Пачка апдейтов при старте не должна вешать UI: бюджет событий на кадр
- **Чужой бинарник TDLib.** sha256 в `tdlib.lock`; для релизов позже добавить вариант с системным TDLib
- **Версия TDLib.** JSON-интерфейс стабилен, но поля добавляются: парсить терпимо к неизвестным полям
- **Нестабильность Zig.** Версия закреплена в `build.zig.zon`; обновлять осознанно
- **Лицензии.** TDLib (Boost), Dear ImGui (MIT), SDL3 (zlib): тексты держим рядом с бинарниками
